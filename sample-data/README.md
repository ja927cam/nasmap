# Sample data

Small files for first-run testing:

* `cambridge-landmarks.geojson` — five points around central Cambridge.
* `cambridge-green-spaces.geojson` — two polygons.
* `cambridge-pubs.csv` — lat/lon CSV.

Import them from **Map → Add layer → Upload file**. They are released under
CC0 / public domain. Coordinates are approximate and for testing only.
